    Лабораторная работа №6¶

    Очистка и трансформация данных. pandas

    Цель работы¶

    Освоение методов очистки и трансформации данных с использованием библиотеки pandas на примере реальных данных из Kaggle (набор данных Titanic). Научиться выявлять и обрабатывать пропуски, преобразовывать типы данных, создавать новые признаки, обрабатывать выбросы и агрегировать данные для последующего анализа.

    Ход выполнения работы¶

    1. Описание набора данных¶

    Для работы использован классический набор данных Titanic с платформы Kaggle. Данные содержат информацию о пассажирах корабля «Титаник», который печально затанул

    Структура данных (до очистки):¶

    • PassengerId: уникальный номер пассажира
    • Survived: выжил ли пассажир (0 - нет, 1 - да)
    • Pclass: класс билета (1, 2, 3)
    • Name: имя пассажира
    • Sex: пол
    • Age: возраст
    • SibSp: количество братьев/сестер/супругов на борту
    • Parch: количество родителей/детей на борту
    • Ticket: номер билета
    • Fare: стоимость билета
    • Cabin: номер каюты
    • Embarked: порт посадки (C, Q, S)

    2. Первичный анализ данных¶

    2.1 Загрузка данных и первые строки¶

    На первом этапе были загружены данные из CSV-файла. Первые 10 строк датафрейма показали структуру и примеры значений

    2.2 Типы данных¶

    Анализ типов данных показал, что большинство числовых признаков имеют тип int64 или float64, а категориальные - object. Это соответствует ожидаемой структуре

    2.3 Анализ пропусков¶

    Было выявлено три столбца с пропущенными значениями:

    • Age: 177 пропусков
    • Cabin: 687 пропусков
    • Embarke: 2 пропуска

    2.4 Статистические характеристики числовых признаков¶

    Статистический анализ describe() показал:

    • Возраст (Age): от 0.42 до 80 лет, среднее ~29.7 лет
    • Стоимость билета (Fare): от 0 до 512.33, среднее ~32.2
    • Выживаемость (Survived): в среднем 38.4% пассажиров выжили

    2.5 Гистограммы распределения¶

    Визуализация числовых признаков показала:

    • Возраст имеет распределение, близкое к нормальному с пиком в районе 20-30 лет
    • Большинство билетов дешёвые, но есть дорогие выбросы

    3. Обработка пропусков¶

    3.1 Столбец Age - возраст¶

    Метод обработки: заполнение медианным значением

    • Среднее: 29.70 лет
    • Медиана: 28.00 лет

    Результат: 177 пропусков успешно заполнены медианой

    Создание признака Age_group:

    На основе заполненного возраста создана категориальная переменная с возрастными группами:

    • Ребенок: 0-12 лет
    • Подросток: 13-18 лет
    • Молодой: 19-35 лет
    • Взрослый: 36-60 лет
    • Пожилой: 61+ лет

    3.2 Столбец Embarked (порт посадки)¶

    Метод обработки: заполнение модой (наиболее частым значением)

    Порт Код Количество
    Саутгемптон S 644
    Шербур C 168
    Квинстаун Q 77

    Наиболее частое значение: S

    Результат: 2 пропуска заполнены значением 'S'

    3.3 Столбец Cabin (каюта)¶

    Метод обработки: признак удалён, вместо него создан новый признак Deck на основе первой буквы номера каюты

    Создан признак, кодирующий палубу (A, B, C, D, E, F, G, T)

    Наиболее распространённая палуба - C

    4. Трансформация данных¶

    4.1 Преобразование Pclass в категориальный тип¶

    Преобразуем исходное числовое значение в новое с первой буквой названия класса

    • F (First - первый класс)
    • S (Second - второй класс)
    • T (Third - третий класс)

    4.2 Создание признака Title (титул)¶

    Из столбца Name были извлечены титулы с помощью регулярного выражения

    Выявлены следующие титулы:

    • M: 517 человек
    • Miss: 182 человека
    • Mrs: 125 человек
    • Master: 40 человек
    • Rare: 26 человек
    • Редкие титулы (Lady, Countess, Capt, Col, Don, Dr, Major, Rev, Sir, Jonkheer, Dona) объединены в группу 'Rare'

    4.3 Преобразование Sex в числовой формат¶

    • female: 0
    • male: 1

    4.4 Создание признаков семейного положения¶

    Создаём признак размера семьи по следующей формуле: FamilySize = SibSp + Parch + 1, где +1 - сам пассажир

    Размер семьи Количество пассажиров
    1 537
    2 159
    3 29
    4+ 66

    Создаём признак, показывающий сколько членов семьи есть у человека:

    IsAlone - 1, если FamilySize - 1, иначе 0

    Статус Количество Доля
    В семье 354 39.7%
    Одинокие 537 60.3%

    5. Обработка выбросов¶

    5.1 Выбросы в признаке Fare¶

    Boxplot показал множество выбросов в верхней области

    IQR-метод:

    Показатель Значени
    Q1 (25-й перцентиль) 7.91
    Q3 (75-й перцентиль) 31.00
    • IQR: 23.09
    • Верхняя граница: 65.63

    Результат: выявлено 116 выбросов (13.0% от всех данных)

    5.2 Winsorization (замена экстремальных значений)¶

    Для обоих признаков Fare и Age применён метод winsorization:

    Признак | 5-й перцентиль | 95-й перцентиль | Заменено значений | |:---:|:---:|:---:| Fare | 7.55 | 77.96 | ~10% | Age | 14.00 | 57.00 |~10% |

    После обработки распределения признаков стали более компактными, выбросы устранены

    6. Агрегация и анализ¶

    6.1 Выживаемость по классам¶

    • 1-й класс (F): 62.3%
    • 2-й класс (S): 47.3%
    • 3-й класс (T): 24.2%

    Вывод: прослеживается чёткая зависимость - чем выше класс, тем выше выживаемость

    6.2 Выживаемость по полу и классу¶

    Класс Женщины Мужчины
    1-й класс 96.8% 36.8%
    2-й класс 92.1% 15.7%
    3-й класс 50.0% 13.5%

    Вывод: женщины выживали значительно чаще мужчин во всех классах.

    6.3 Медианный возраст по портам посадки¶

    Порт Медианный возраст
    Cherbourg (C) 30.0 лет
    Queenstown (Q) 26.0 лет

    6.4 Сводные таблицы выживаемости¶

    По возрастным группам:

    • Ребенок (0-12): 59.3%
    • Подросток (13-18): 39.1%
    • Молодой (19-35): 35.7%
    • Взрослый (36-60): 43.3%
    • Пожилой (61+): 16.7%

    По титулам и полу:

    Наибольшая выживаемость у женщин с титулами Mrs (79.8%) и Miss (70.8%), наименьшая - у мужчин с титулом Mr (15.7%)

    7. Метрики качества очистки данных¶

    Вывод¶

    В ходе выполнения лабораторной работы были освоены основные методы очистки и трансформации данных с использованием библиотеки pandas на примере набора данных Titanic. Выявлены и обработаны пропуски в трёх столбцах: для количественного признака Age применено заполнение медианой (177 пропусков), для категориального Embarked — модой (2 пропуска), а столбец Cabin преобразован в новый признак Deck на основе первой буквы каюты с последующим удалением исходного. Созданы новые признаки: Age_group (5 возрастных групп), Title (титулы Mr, Mrs, Miss, Master, Rare), FamilySize, IsAlone, а также выполнены преобразования Pclass в категориальный тип (F, S, T) и Sex в числовой формат (0/1).

    Обработка выбросов методом winsorization для признаков Fare и Age (замена на 5-й и 95-й перцентили) позволила уменьшить влияние экстремальных значений без потери данных. Агрегационный анализ выявил чёткую зависимость выживаемости от класса обслуживания (1-й класс — 62.3%, 3-й класс — 24.2%) и пола (женщины выживали значительно чаще мужчин во всех классах). Корреляционный анализ показал, что наибольшее влияние на выживаемость оказывают пол (-0.54) и класс обслуживания (-0.34). Процент заполнения данных после очистки составил 99.98%.

    Полученные навыки работы с пропусками, трансформации признаков, обработки выбросов и агрегации данных являются фундаментальными для последующего анализа данных и построения моделей машинного обучения. Очищенный датасет сохранён в CSV-файл и готов к дальнейшему использованию.
